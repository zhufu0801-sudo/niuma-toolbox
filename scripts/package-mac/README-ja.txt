オフィスツールボックス 0.16.0 · macOS 版

インストール
1. 展開したら、Finder で「install.command」を右クリック →「開く」を選びます（App Store 以外から入手したため、初回はこの方法で開きます）。
2. 画面の案内に従って、WPS と Microsoft Office のどちらに入れるかを選びます。Node.js がない場合は、公式サイト nodejs.org からダウンロードするか確認されます（無料）。
3. Microsoft Office 版を入れるときは、macOS のログインパスワードを求められます。このパソコンの localhost 専用の証明書を信頼するためです。
4. WPS または Word / Excel / PowerPoint を完全に終了して開き直します。
   - WPS：上部に「ツールボックス」タブが表示されます。
   - Microsoft Office：「挿入 → アドイン → 個人用アドイン」から「オフィスツールボックス」を開きます。

補足
- 画像から文字の読み取りには macOS 標準の文字認識を使います。日本語は macOS 13 以降、中国語は macOS 11 以降が必要です。
- 画像の圧縮には macOS 標準の sips を使います。
- WPS の Mac 版はバージョンによってアドイン対応が異なります。タブが表示されないときは WPS を最新版に更新してください。
- PDF 内の画像の取り出しは Windows 版のみ対応です。PDF を Word にする機能（文字・スキャン PDF の読み取り）は Mac でも使えます。

アンインストール
「uninstall.command」を右クリック →「開く」。設定・AI の設定・バックアップは残ります。

今回は Mac 実機で検証していません。PDF の画像加工は画像コンポーネントが必要で、不足時は案内が表示されます。重要なファイルは先にバックアップしてください。AI は任意で、利用時は選択したサービスに内容を送信します。
