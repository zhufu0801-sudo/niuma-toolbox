オフィスツールボックス 0.16.0 · Windows 64 ビット版（試用版）

インストール（約 2 分）
1. ZIP 全体を決まったフォルダー（例：D:\OfficeToolbox）に展開します。圧縮ファイルの中から直接開かないでください。
2. Start.cmd をダブルクリックし、表示された画面で WPS と Microsoft Office のどちらに入れるか選びます（両方も可）。
   Microsoft Office を選ぶと、Windows が「OfficeToolbox localhost」証明書を信頼するか確認します。「はい」を選んでください（このパソコンのアドイン専用）。
3. 作業中の文書を保存し、WPS をいったん完全に終了して開き直すと、上部に「ツールボックス」タブが表示されます。
4. 次回からはパソコン起動後、先にデスクトップの「Office Toolbox」をダブルクリックしてから WPS を開いてください。

使い方
- 上部の「ツールボックス」タブで、処理したい内容を選んで（選ばなければ文書全体）ボタンを押します。ボタンにマウスを乗せると説明が出ます。
- 「ツールボックスを開く」で右側にサイドバーが開き、「技の案内」から全機能を検索・お気に入り登録できます。
- AI 機能は任意です。「設定 → AI サービス」で自分の API キーを入れると、AI チャット・要約・翻訳などが使えます。

安心して使うために
- 通常の整理・ファイル処理はこのパソコン内で行います。任意の AI 機能を設定した場合は、送信した内容が選択したサービスに送られます。
- 出力は別ファイルに保存します。現在の文書を変更する場合は先に確認します。WPS Spreadsheets のツールによる変更は Ctrl+Z で戻せないため、重要なファイルは先にバックアップしてください。
- 試用版です。大切なファイルは先にコピーしてから試してください。

困ったときは
- タブが表示されない：デスクトップの「Office Toolbox」をダブルクリックしてから、WPS を完全に終了して開き直してください。
- 「ローカルサービスに接続できません」と表示される：デスクトップの「Office Toolbox」をダブルクリックし、数秒待ってから再度お試しください。
- 会社のパソコンで Start.cmd を実行できない：管理者に相談してください。セキュリティソフトは止めないでください。

アンインストール
Uninstall.cmd をダブルクリックしてから、フォルダーごと削除してください。文書とバックアップは削除されません。

0.16.0 の追加機能
12 種類の PPT テンプレート（中日 24 ファイル）、8 種類のビジネス帳票、印刷前チェック、FAX 用コピー、封筒・ラベル、縦書き、印影、PDF 集約・小冊子・割印、MCP 接続、診断出力、任意の更新確認。

注意点
OCR の金額・小数点は必ず確認してください。帳票の登録番号・税率・金額は発行前に確認してください。印影画像は電子署名や認証ではありません。PDF 加工の結果は画像で、元の検索文字・リンク・署名は保持されません。FAX 最適化後は改ページを確認してください。
AI 機能は任意です。MCP 操作は文書内で確認します。Office サイドバーは開いたままにしてください。更新の自動ダウンロード・インストールは行いません。
