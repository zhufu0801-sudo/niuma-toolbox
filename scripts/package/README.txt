办公工具箱 0.16.0 · Windows 64 位版（试用版）

安装与启动
1. 解压整个 ZIP，再运行 Start.cmd。选择 WPS、Microsoft Office 或两者。
2. Office 需要仅供 localhost 使用的证书；核对 OfficeToolbox localhost 名称后，由你本人决定是否信任。
3. 保存文档并完全退出 WPS 后重新打开。以后先双击桌面 Office Toolbox 启动本机服务。
4. WPS 顶部“办公工具箱”打开侧栏；Office 顶部“办公工具箱”打开加载项侧栏。

本版新增
- 12 套场景 PPT 模板，中文和日文共 24 份；模板副本、版式工作室和 WPS 套用入口。
- 8 套商务表格，消费税 10%／8% 分别汇总，三种尾数处理，人民币金额大写。
- 打印前检查、黑白／传真副本、传真封面、信封／地址标签、日文竖排、印章、PDF 多页合一／小册子／骑缝章。
- MCP 连接 AI 助手、诊断摘要导出、可选版本检查、首次使用引导。

使用说明
- 普通整理、模板与文件处理在本机运行。AI 为可选功能，接入自己的 API 后，提交的内容会发送给你选择的服务商。
- MCP 助手只能在工具箱打开时读取或请求操作；修改前会在文档里确认。Office 侧栏必须保持打开。
- 输出另存副本；修改当前文档会先确认。WPS 表格工具改动不能用 Ctrl+Z 恢复，重要文件务必先保存备份。
- OCR 请核对识别结果，尤其是金额、小数点、手写、竖排和复杂背景。日文识别需要系统日文 OCR 语言组件。
- 商务模板是填写辅助；开具前核对双方资料、注册号、税率和金额。电子印章只是图片，不提供电子签名或认证能力。
- PDF 排版、传真和骑缝章输出为图片型，原有搜索文字、链接与签名不会保留。传真优化改变字号和线条，请核对分页。
- 不自动发送传真或邮件，不自动出纸。打印机双面和纸盒请自行选择；先看打印预览。
- 工具箱不自动下载或安装更新。版本信息地址未设置或断网时不会弹出错误。
- 第三方组件许可见 app/THIRD-PARTY-NOTICES.txt。无担保，请先用副本验证重要工作。

卸载
运行 Uninstall.cmd；用户设置、AI 配置、文档和备份会保留。
Mac 包单独提供；本次没有 Mac 真机，未实测。详细验证范围见更新说明和验收记录。
