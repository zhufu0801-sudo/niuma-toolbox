# 办公工具箱 · 企业批量部署说明（0.11）

适合 IT 管理员给多台电脑统一安装。本说明里的命令都**按“每个 Windows 用户”执行**：工具箱登记在当前用户名下（WPS 的 `%APPDATA%\kingsoft\wps\jsaddons\publish.xml`、Office 的 `HKCU\...\WEF\Developer`、当前用户证书库），不需要管理员权限，也不改系统级设置。

> 验收情况：0.11 新增的 `-NoLaunch`、`-NoShortcut` 和 `preset` 文件夹，只在云端做了脚本内容检查和配置文件读取测试，**还没有在 Windows 上实际跑过批量安装**。请先在一台测试电脑、一个测试账号上走一遍。

## 1. 准备安装文件夹

1. 把 ZIP 解压到每台电脑上**固定、当前用户可写**的位置，例如 `%LOCALAPPDATA%\Programs\OfficeToolbox`。解压后不要再移动（移动后要重新运行安装）。
2. 从网上下载的 ZIP 会带“来自网络”标记，脚本可能被拦或弹安全提示。解压后在 PowerShell 里执行一次：
   ```powershell
   Get-ChildItem -LiteralPath "$env:LOCALAPPDATA\Programs\OfficeToolbox" -Recurse | Unblock-File
   ```
3. 如需统一配置，在 `Initialize.ps1` 旁边建 `preset` 文件夹（示例见安装包 `preset-example`）：

| 文件 | 作用 | 说明 |
|---|---|---|
| `preset\settings.json` | 界面语言、默认字体等 | 只写要改的项，其余用默认值 |
| `preset\ai.json` | 预设 AI 服务商、地址、模型、个人信息保护方式 | 建议**不放 Key**，由员工自己填；放了 Key 也会在第一次使用时改用 Windows 加密保存 |
| `preset\plugins\*.mjs` | 公司自己的隐私保护插件 | 复制到 `app\plugins`，接口见 `app\plugins\README.md` |

**只在文件不存在时复制**：员工已经改过的设置、已填的 Key、同名插件都不会被覆盖。`preset` 里的 JSON 格式不对时，安装会停止并提示，不会写入半成品。

## 2. 无人值守安装

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\Programs\OfficeToolbox\Initialize.ps1" -Targets wps -NoLaunch
```

| 参数 | 作用 |
|---|---|
| `-Targets wps` / `office` / `wps,office` | 跳过选择窗口，直接登记到指定软件 |
| `-NoShortcut` | 不在桌面建 “Office Toolbox” 快捷方式 |
| `-NoLaunch` | 装完不打开工具箱（适合登录脚本） |

返回值：成功为 0，失败为 1，错误信息写在控制台，可由部署工具收集。

**Microsoft Office 版的限制**：`office` 需要在当前用户证书库信任一张本机自签证书，Windows 会弹出确认框，必须由员工点“是”，因此**无法完全静默**。如果只部署 WPS 版，可以完全静默。

可以放进登录脚本（每次登录都跑也安全：重复登记只会覆盖工具箱自己的三项，其他插件保留，原文件先备份）。

## 3. AI 与个人信息保护的建议

- `privacy.mode` 推荐 `mask`（发送前自动隐藏身份证号、手机号、邮箱、银行卡号、日本个人编号，回答回来再还原）。`remind` 会每次询问，`off` 关闭内置保护。
- 公司规定（如“标有机密的内容不能外发”“项目代号要隐藏”）用插件实现。插件**无论员工把保护方式选成什么都会运行**；插件加载失败时所有 AI 功能停用，不会在没有保护的情况下发出。
- 有公司内部 AI 网关时，`ai.json` 里用 `"provider": "custom"` 加网关地址；只允许本机处理时用 `"provider": "ollama"`。
- Key 用 Windows 当前用户加密保存（DPAPI），换电脑或换 Windows 用户需要重新填写。

## 4. 升级与卸载

- 升级：解压新版本覆盖到同一文件夹（`app\generated` 里的卡片、设置、AI 设置保留），再运行一次第 2 步的命令。
- 卸载：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File "...\Uninstall.ps1"`。会停止后台、移除 WPS 和 Office 登记、删除本机证书、快捷方式和 AI 设置文件；卡片和设置保留，确认后再删整个文件夹。

## 5. 常见限制

- 组策略把 PowerShell 执行策略设成 `AllSigned` 时，未签名的脚本无法运行（`-ExecutionPolicy Bypass` 也会被组策略覆盖）。见《代码签名准备》。
- 后台固定监听 `127.0.0.1:39127`（Office 版另用 `39128`），只对本机开放。同一台电脑多人同时登录（远程桌面服务器）时端口会冲突，目前**不支持**多用户共用一台服务器。
- 不设置开机自启。员工每次开机后双击 “Office Toolbox” 一次；或在登录脚本里运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "...\app\Launch.ps1" -NoOpen`（只启动后台，不打开窗口）。
