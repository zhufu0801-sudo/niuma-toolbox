# オフィスツールボックス · 企業向け一括導入ガイド（0.11）

複数のパソコンにまとめて導入する IT 管理者向けです。コマンドは**Windows ユーザーごと**に実行します。登録先はすべて現在のユーザー（WPS の `%APPDATA%\kingsoft\wps\jsaddons\publish.xml`、Office の `HKCU\...\WEF\Developer`、現在のユーザーの証明書ストア）で、管理者権限は不要、システム全体の設定は変更しません。

> 検証状況：0.11 で追加した `-NoLaunch`・`-NoShortcut`・`preset` フォルダーは、クラウド上でのスクリプト内容チェックと設定ファイルの読み込みテストのみ行いました。**Windows 上での一括導入はまだ実行していません。**まずテスト用のパソコン・アカウントで一度お試しください。

## 1. インストール用フォルダーの準備

1. ZIP を各パソコンの**固定された、ユーザーが書き込める場所**（例：`%LOCALAPPDATA%\Programs\OfficeToolbox`）に展開します。展開後は移動しないでください（移動した場合は再度インストールを実行）。
2. インターネットから取得した ZIP には「インターネットから取得」の印が付き、スクリプトがブロックされることがあります。展開後に PowerShell で一度実行してください：
   ```powershell
   Get-ChildItem -LiteralPath "$env:LOCALAPPDATA\Programs\OfficeToolbox" -Recurse | Unblock-File
   ```
3. 設定を統一する場合は、`Initialize.ps1` と同じ場所に `preset` フォルダーを作ります（例はパッケージ内の `preset-example`）：

| ファイル | 内容 | 補足 |
|---|---|---|
| `preset\settings.json` | 表示言語、既定のフォントなど | 変更する項目だけ書けば、ほかは既定値 |
| `preset\ai.json` | AI サービス・接続先・モデル・個人情報保護の方式 | API キーは**入れず**各自で入力する運用を推奨。入れた場合も初回使用時に Windows の暗号化で保存し直します |
| `preset\plugins\*.mjs` | 自社の個人情報保護プラグイン | `app\plugins` にコピーされます。仕様は `app\plugins\README.md` |

**ファイルがない場合だけコピーします。**利用者が変更した設定、入力済みのキー、同名のプラグインは上書きしません。`preset` の JSON が正しくない場合はインストールを止めて表示し、中途半端な状態にはしません。

## 2. 無人インストール

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\Programs\OfficeToolbox\Initialize.ps1" -Targets wps -NoLaunch
```

| パラメーター | 内容 |
|---|---|
| `-Targets wps` / `office` / `wps,office` | 選択画面を出さずに指定したソフトへ登録 |
| `-NoShortcut` | デスクトップに「Office Toolbox」ショートカットを作らない |
| `-NoLaunch` | インストール後にツールボックスを開かない（ログオンスクリプト向け） |

終了コードは成功 0、失敗 1。エラー内容はコンソールに出力されます。

**Microsoft Office 版の制限**：`office` では、このパソコン専用の自己署名証明書を現在のユーザーの証明書ストアで信頼する必要があり、Windows の確認画面で利用者が「はい」を押す必要があります。そのため**完全な無人化はできません**。WPS 版だけなら完全に無人で導入できます。

ログオンスクリプトに入れて毎回実行しても問題ありません（ツールボックスの 3 項目だけを登録し直し、ほかのアドインは残し、元ファイルはバックアップします）。

## 3. AI と個人情報保護の推奨設定

- `privacy.mode` は `mask` を推奨（送信前に身分証番号・電話番号・メールアドレス・カード番号・マイナンバーを伏せ、回答で元に戻す）。`remind` は毎回確認、`off` は内蔵保護をオフ。
- 社内ルール（「極秘」と書かれた内容は外部に出さない、プロジェクト名を伏せる等）はプラグインで実装します。プラグインは**利用者がどの方式を選んでも必ず動きます**。読み込みに失敗した場合はすべての AI 機能を停止し、保護なしで送信することはありません。
- 社内 AI ゲートウェイがある場合は `"provider": "custom"` とゲートウェイの URL を指定。パソコン内だけで処理したい場合は `"provider": "ollama"`。
- API キーは Windows の現在のユーザーで暗号化（DPAPI）して保存します。パソコンや Windows ユーザーが変わった場合は入力し直しが必要です。

## 4. アップデートとアンインストール

- アップデート：新しいバージョンを同じフォルダーに上書き展開（`app\generated` のカード・設定・AI 設定は残ります）し、手順 2 のコマンドをもう一度実行。
- アンインストール：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File "...\Uninstall.ps1"`。バックグラウンドの停止、WPS と Office の登録解除、証明書・ショートカット・AI 設定ファイルの削除を行います。カードと設定は残るので、不要と確認してからフォルダーごと削除してください。

## 5. 主な制限

- グループポリシーで PowerShell の実行ポリシーが `AllSigned` の場合、署名のないスクリプトは実行できません（`-ExecutionPolicy Bypass` もポリシーで上書きされます）。「コード署名の準備」を参照。
- バックグラウンドは `127.0.0.1:39127`（Office 版は `39128` も）で待ち受け、このパソコンからだけ接続できます。リモートデスクトップサーバーなど 1 台を複数人で同時に使う環境ではポートが競合するため、**現在は非対応**です。
- 自動起動は設定しません。起動後に「Office Toolbox」を一度ダブルクリックするか、ログオンスクリプトで `app\Launch.ps1 -NoOpen`（バックグラウンドだけ起動）を実行してください。
