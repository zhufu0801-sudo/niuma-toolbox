# 日文版 WPS 菜单名对照（未在日文版 WPS 实测）

工具箱的日文界面、方法卡和提示里，会写“到哪个菜单点哪一项”。开发电脑上装的是中文版 WPS 12.1，**没有日文版 WPS 可以核对**，下面是目前日文界面用的写法和依据，供以后在日文版 WPS 上逐项核对、修正。

核对方法：在日文版 WPS 里按左列中文版的位置找到同一个按钮，把实际显示的名字填进“实测名称”，不一致的告诉我改词典（`public/i18n-ja.js` / `i18n-ja-extra.js`）。

## 公开资料里能确认的写法

- KINGSOFT 日文支持页（隔行填色）：「ホーム」タブ → 「書式」 → 「条件付き書式の設定」，对话框名为「条件付き書式」。工具箱现在写的是「条件付き書式」，菜单项可能实际叫「条件付き書式の設定」。来源：<https://support.kingsoft.jp/wps/wps_s/kso_167.html>
- KINGSOFT 日文资讯页（删除重复数据）：「データ」タブ → 「重複する値を蛍光ペンで表示」 →「重複する値を削除」；条件格式里有「セルの強調表示ルール」→「重複する値」。工具箱的“删除重复行”是自己的按钮，不受影响；方法卡里提到重复项时可改成这个写法。来源：<https://home.kingsoft.jp/news/app/wps/230627.html>
- 以前的 kingsoft.jp 博客地址现在会跳转到 wps.com，日文版 WPS 的官方资料可能已迁到 <https://www.wps.com/ja-JP/>，下次核对可从那里找。

## 已知的不一致（工具箱自己的问题）

- “办公工具箱”在日文界面里有两种译法：页面标题用「オフィスツールボックス」，顶部功能区标签用「ツールボックス」，桌面快捷方式叫「Office Toolbox」。以后统一时三处一起改。

## 不需要核对的部分

Microsoft Office 版（Excel / Word / PowerPoint）的日文菜单名本来就按微软日文版写，和上表 B 类一致。
